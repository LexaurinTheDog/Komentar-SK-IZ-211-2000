# Komentár k zákonu č. 211/2000 Z. z., o slobodnom prístupe k informáciám

Odborný komentár k slovenskému Zákonu o slobode informácií — základnému predpisu upravujúcemu právo na prístup k informáciám vo verejnej správe, so **49 paragrafovými jednotkami** (§ 1 – § 33b) s doslovným znením a vecným výkladom.

Konsolidované znenie k **4. 2. 2026**, zdroj [slov-lex.sk](https://www.slov-lex.sk/static/SK/ZZ/2000/211/20260204.html).
